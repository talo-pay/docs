# Transactions API

Consulta las transacciones de tu cuenta. Cada vez que se recibe una transferencia bancaria (ya sea por un pago único o un cliente fijo), se genera una transacción.

---

## Listar transacciones

```http
GET https://api.talo.com.ar/transactions/
```

### Sandbox

```http
GET https://sandbox-api.talo.com.ar/transactions/
```

<Callout type="info">
	Requiere `Authorization: Bearer` header.
</Callout>

### Query parameters

| Campo                        | Tipo     | Requerido | Descripción                                          |
| ---------------------------- | -------- | --------- | ---------------------------------------------------- |
| `user_id`                    | `string` | Sí        | ID del usuario cuyas transacciones se quieren listar  |
| `team_id`                    | `string` | No        | Filtrar por equipo                                    |
| `limit`                      | `string` | No        | Cantidad de resultados por página (numérico)          |
| `start_date`                 | `string` | No        | Fecha de inicio (ISO 8601)                            |
| `end_date`                   | `string` | No        | Fecha de fin (ISO 8601)                               |
| `cursor_user_id`             | `string` | No        | User ID del cursor para paginación                    |
| `cursor_transaction_id`      | `string` | No        | Transaction ID del cursor para paginación             |
| `cursor_creation_timestamp`  | `string` | No        | Timestamp del cursor para paginación                  |

<Callout type="tip">
	Para paginar, usa los valores `cursor_user_id`, `cursor_transaction_id` y `cursor_creation_timestamp` del campo `lastEvaluatedKey` de la respuesta anterior.
</Callout>

### Ejemplo

```bash
curl -H "Authorization: Bearer $TALO_TOKEN" \
  "https://sandbox-api.talo.com.ar/transactions/?user_id=f61876b0-10a5-4e39-8e2c-17343b3fa1b6&limit=10"
```

## Consultar una transacción

```http
GET https://api.talo.com.ar/transactions/{transaction_id}
```

### Sandbox

```http
GET https://sandbox-api.talo.com.ar/transactions/{transaction_id}
```

### Parámetros del path

| Campo            | Tipo     | Descripción                    |
| ---------------- | -------- | ------------------------------ |
| `transaction_id` | `string` | ID de la transacción           |

### Query parameters

| Campo     | Tipo     | Requerido | Descripción         |
| --------- | -------- | --------- | ------------------- |
| `user_id` | `string` | Sí        | ID del usuario dueño de la transacción |

### Ejemplo

```bash
curl -H "Authorization: Bearer $TALO_TOKEN" \
```

## Campos de la transacción

| Campo                | Tipo       | Descripción                                                    |
| -------------------- | ---------- | -------------------------------------------------------------- |
| `transaction_id`     | `string`   | ID único de la transacción                                     |
| `user_id`            | `string`   | ID del usuario dueño                                           |
| `transactionType`    | `string`   | Tipo: `INBOUND`, `OUTBOUND`, `REFUND`                          |
| `amount`             | `string`   | Monto neto de la transacción                                   |
| `gross_amount`       | `string`   | Monto bruto recibido                                           |
| `address`            | `string`   | CVU receptor                                                   |
| `address_alias`      | `string`   | Alias receptor                                                 |
| `currency`           | `string`   | Moneda de la transacción                                       |
| `network`            | `string`   | Red de procesamiento                                           |
| `commission`         | `number`   | Porcentaje de comisión                                         |
| `commission_amount`  | `string`   | Monto de la comisión                                           |
| `taxes`              | `array`    | Impuestos aplicados (`tax_type`, `tax_rate`, `tax_amount`)     |
| `transaction_status` | `string`   | Estado: `PROCESSED`                                            |
| `transaction_data`   | `object`   | Datos del procesamiento bancario                               |
| `payment_id`         | `string`   | ID del pago asociado (si aplica)                               |
| `customer_id`        | `string`   | ID del cliente asociado (si aplica)                            |
| `creation_timestamp` | `string`   | Fecha de creación (ISO 8601)                                   |
